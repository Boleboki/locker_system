# 🔒 Smart Locker Management System

A web-based access control and management platform for RFID/card-operated smart lockers, built primarily for student dormitories and facility management. It allows administrators to manage RFID card readers, track user credentials, and configure system settings through a modern, responsive interface.

---

## 📌 Key Features

**Core & Interface:**
* **Multilingual Support**: Toggle seamlessly between English and Serbian language options.
* **Theme Customization**: Built-in Dark and Light mode options for modern user experience.
* **Role-Based Access**: Separate user and administrator interfaces with custom access levels.

**Admin Dashboard:**
* **Reader Management**: Complete interface to add, edit, and configure RFID/card readers.
* **Advanced Data Tables**: Dynamic tables for readers and users featuring pagination, real-time search, and column sorting.
* **User & Account Management**: Add, delete, and update user accounts, alongside secure password reset functionalities.
* **System Settings**: Global configuration panel for system behavior and system-wide rules.
